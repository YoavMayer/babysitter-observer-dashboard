7. What is still unproven

  • CI going green. The one documented failure is fixed; the other 7 jobs in that gate could fail for their own reasons. Only a real run shows it.
  • latest moving to 6.0.3. Tag logic is correct (main → latest), but it was manually rolled backward once, outside CI. Verify with npm view … dist-tags after publishing.
  • The ^6.0.0 SDK range. The observer reads babysitter's on-disk format using hand-written fixtures, not SDK-generated ones. An SDK format change breaks the observer with every test still green. This is the next real breakdown.
  • tailwindcss unpinned ^4. Three builds of identical source produced three different CSS bytestreams (4.2.1 / 4.3.0 / 4.3.3). Visually inert, but byte-exact CSS can never be asserted at release time.
